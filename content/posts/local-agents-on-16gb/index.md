### Runner-Up Performance

If you're running into VRAM constraints and need to be more frugal, consider these models with a trade-off:

> **Pro Tip:** Use `llama.cpp` quantization schemes like Q4_0 or even Q5_0 for better quality. The difference between 4-bit and 5-bit quantization is often negligible while adding minimal overhead to VRAM usage.

### What Other Developers Might Consider (If Reading This)

- If you're using an AMD GPU, ensure you have ROCm or Vulkan compatibility configured. Models still work well but may run slightly slower than NVIDIA equivalents. Qwen models on ROCm are excellent for this setup.
- For agents, consider running multiple instances with different quantizations for fallback or parallelization
- The `qgen` project from qwen-mcp-server is a good local execution framework for autonomous agents
- Use `ollama run llama3.1` if you want raw speed and decent reasoning — it's the new default for many things
